# ストキャスエイト (Sto8)

TradingView 用 Pine Script v6 インジケーター。
期間の異なるストキャスティクス8本を1つのペインに表示し、全体の買われすぎ・売られすぎを判定します。
YouTube動画で紹介されていたMT4インジケーター「ストキャスエイト by Saikix」を参考に再現したものです。

## 特徴

- ストキャスティクス8本を同時表示（短期4本・長期4本）
- 左上のパネルに各本の値・判定・総合判定を表示
- 「全体買われすぎ」「全体売られすぎ」「ロング決済」「ショート決済」をラベルで表示
- 「全体買われすぎ」「全体売られすぎ」のアラートに対応

## ファイル

| ファイル | 内容 |
|---|---|
| `sto8.pine` | インジケーター本体（Pine Script v6） |

## 導入方法

1. TradingView のチャート下部「Pineエディタ」を開く
2. `sto8.pine` の内容を貼り付けて保存
3. 「チャートに追加」を押す

## 設定項目

### 期間

| 項目 | 初期値 |
|---|---|
| 短期1〜4 | 3 / 5 / 8 / 10 |
| 長期1〜4 | 30 / 35 / 40 / 45 |

### 判定

| 項目 | 初期値 | 説明 |
|---|---|---|
| %K平滑化 | 1 | 1で平滑化なし |
| 買われすぎライン | 80 | 80以上で「買われすぎ」 |
| 売られすぎライン | 20 | 20以下で「売られすぎ」 |
| 全体判定に必要な本数 | 8 | 8本中、何本が条件を満たしたら「全体」とするか |
| シグナル表示 | ON | ラベルの表示切替 |
| パネル表示 | ON | 左上パネルの表示切替 |

### パネル位置

コード冒頭の `topSpacer` の数値で、パネルの縦位置を調整します。
値を大きくするほどパネルが下がり、`0` で一番上に詰まります。

```pine
topSpacer = 2
```

## 判定ルール

### 各本の判定

| 条件 | 表示 |
|---|---|
| 買われすぎライン以上 | 買われすぎ |
| 50以上〜買われすぎライン未満 | 強気圏 |
| 売られすぎライン超〜50未満 | 弱気圏 |
| 売られすぎライン以下 | 売られすぎ |

### 総合判定

8本の平均値で判定します。

| 平均値 | 表示 |
|---|---|
| 買われすぎライン以上 | 買われすぎ状態 |
| 50以上〜買われすぎライン未満 | 強気状態 |
| 売られすぎライン超〜50未満 | 弱気状態 |
| 売られすぎライン以下 | 売られすぎ状態 |

## シグナル

| 表示 | 条件 |
|---|---|
| 全体買われすぎ | 8本中「全体判定に必要な本数」以上が80以上になった最初のバー |
| 全体売られすぎ | 8本中「全体判定に必要な本数」以上が20以下になった最初のバー |
| ロング決済 | 全体買われすぎの後、短期1（期間3）が80を上から下に抜けたバー |
| ショート決済 | 全体売られすぎの後、短期1（期間3）が20を下から上に抜けたバー |

- 「全体」の表示は、条件を満たした最初の1回だけ出ます。
- 決済は、直前に「全体」の表示が出ている場合にだけ出ます。
- 動画側の正確な条件は不明のため、決済の条件は推定です。
- 8本すべてが同時に条件を満たすことは少ないため、表示が少ない場合は「全体判定に必要な本数」を6〜7に下げてください。

## アラートの設定

アラートは「全体買われすぎ」「全体売られすぎ」の2種類です（決済は対象外）。

1. チャート上で `Alt + A` を押す
2. 「条件」で「ストキャスエイト」を選ぶ
3. 下のプルダウンで「alert() 関数呼び出しのみ」を選ぶ
4. 「通知」タブで受け取り方法を選ぶ
5. 「作成」を押す

注意点:

- 通知は、足の途中で条件を満たした最初の時点で、足ごとに1回届きます（足の確定を待ちません）。
- 足の確定前に条件が外れる場合があります（通知後に条件が戻っても、その足では再通知されません）。
- 銘柄ごと、時間足ごとにアラートの作成が必要です。
- TradingView のアラートは作成時点のコードで動き続けます。コードを更新した場合は、古いアラートを削除して作り直してください。

## 制限事項

- オシレーター用ペインのスクリプトは、メインチャート上に描画できません。シグナルはペイン内のラベルとして表示されます。
